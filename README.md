## 🧠 我如何使用 AI

我不会只让 AI 补几行代码，而是把它放进完整的软件工程链路：

```text
理解业务与代码 → 拆解任务 → 调用工具 → 实现与审查
        → 自动化测试 → 浏览器回归 → 部署验证 → 留下可追溯证据
```

- 让 Agent 读取真实代码、配置、日志与运行状态，而不是脱离上下文猜答案；
- 使用 Skills、MCP 与自动化，把经验沉淀为可复用、可执行的工程能力；
- 用多智能体并行完成探索、实现、审查和验证，提高复杂项目的推进效率；
- 对凭证、权限、外部写入和生产环境保持清晰边界；
- 以测试结果、运行证据和可回滚交付作为“完成”的标准。
