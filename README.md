我把 AI 当作可编排、可验证的工程参与者，而不只是代码补全工具：

- 用 Agent 与工具还原真实代码路径、配置和运行边界；
- 将探索、实现、测试、审查和浏览器回归拆成可并行任务；

- 以测试结果、运行证据和可回滚交付作为“完成”的标准。
